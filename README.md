# Griefer Manhunt Tools

_**This is the official manhunt mod used by Griefer and Mike in their manhunt videos.**_

# ⚡Ptrack⚡

In this mod, you'll find a plethora of challenges able to be used by you and your friends for a very fun time! You can use this mod on a server, a hosted multiplayer world, or a LAN world, it doesn't matter!

### **Features 🔥**


- A compass that allows for cross-dimensional tracking
- A menu to select which player to track
- Fully customizable manhunt challenges
- A settings menu that allows for any manhunt-related ideas you have to spring to life
- A datapack created from the mind of manhunt veterans
- Compatibility to a few other versions
- Endless fun with friends

### **Current Challenges:**


- Regular Manhunt
- Manhunt Tag
- Tank vs Assassin
- Netherite Assassins
- Timed Challenge (Yet to be used!)

And more to come!

## How to use
When Loading into the Minecraft world, have the runner run `/runner` and the hunters run `/hunter`
## Gamemodes

| Name               | Description |
|--------------------| ----------- |
| Classic            | A Runner with one life tries to beat the game while Hunters are given compasses to try and track the Runner down and stop them from doing so |
| Manhunt TAG        | A gamemode incentivizing betrayal among teammates, where a runner is chosen at the start, and upon being killed, the hunter who did so becomes the new runner. Whoever ends as the runner after killing the Ender Dragon or successfully surviving a given time limit wins |
| Tank VS Assassin   | A Tank is provided with a weak sword but protective armor, while a number of Assassins are given weak armor yet effective swords |
| Netherite Assassin | A Runner gets nothing, but typically may have more than one life. The hunters are given full netherite armor and netherite swords to slay the runner |
| Timed Challenge    | This challenge is the same as manhunt, yet on a timer. A Runner is chosen, and the Hunters' goal is to try and kill the Runner as many times as possible. Whenever the Runner dies, 10 minutes are added to a timer, increasing the time that the Runner must survive to win. If the Hunters get the timer to double what it originally is, they win. |

## ⚙️Settings⚙️

After you have selected the gamemode you would like to play, you can customize your games settings with the command `/manhunt set`
Below is a list of each setting and what it does, most are self-explanitory however.

| Name | Description |
| ----------- | ----------- |
| Give Compass | Provides the Hunters with a tracking compass |
| Show Locator Bar | Shows the locator bar in place of the experience bar |
| Give Glowing To Runner | Gives the Runner the glowing effect, allowing the Hunters to see the Runner through walls |
| Instant Respawn | When a Hunter dies, they instantly respawn without the wait |
| Keep Inventory | Hunters/Runner keeps inventory upon death |
| Show Timer On Action Bar | Shows the timer for timed challenges |
| Runner Has One Life | Limits the runner to one life for certain challenges |
| Colored Nametags | Color codes nametags (Hunters - Red, Runners - Green) |
| Display Winners | Displays the winner at the end of a challenge |

## The Compass 🧭

The video shown above is a challenge that utilizes the manhunt gamemode, with a few mods added to a world. There were three hunters in the video, who were all able to utilize the compass between dimensions flexibly to locate the runner, which made for a great and intense video.

When using this compass yourself, you will be given it after the Runner goes through all of the neccessary steps to set up the challenge. The compass will automatically track the Runner, and when they go into the nether or end, it will save their portal locations for you to go to.

The more advanced aspect of this compass is the fact that if you need, you can select one of your fellow hunters to track by pressing `SHIFT + RIGHT CLICK` you will then be opened to a menu to select who to track.
